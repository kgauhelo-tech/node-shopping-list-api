# Title: Task 6 - Shopping List API

## Endpoints

- The endpoint for adding an items is:
  - /items
  - It returns nothing
  - Method for adding the items is POST
  - it returns the added item

- The endpoint for getting all items:
  - /items
  - The necessary method is GET
  - it returns a list of items

- The endpoint for getting a Single item by ID:
  - /items/:id
  - The necessary method is GET
  - It returns the found item

- The endpoint for updating an item:
  - /items/:id
  - The required method is PUT
  - It returns nothing

- The endpoint for deleting an item:
  - /items/:id
  - The necessary method is DELETE
  - It returns nothing
